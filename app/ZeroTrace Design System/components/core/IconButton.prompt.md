# IconButton

Icon-only action in dense chrome. Rest opacity is ramp .72, hover 1.00 — never a colour change.

\`\`\`jsx
<IconButton name="copy" label="Copy payload" />
<IconButton name="more-horizontal" label="Row actions" size={24} />
<IconButton name="x" label="Close" onDark />
\`\`\`

\`label\` is mandatory. In marketing there are no icon buttons.
